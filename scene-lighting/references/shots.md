# 镜头适配与连续性

## 景别

| 景别 | 灯光段落里额外写什么 |
|---|---|
| 远景 / 全景 | 光池和暗区的分布（"只有窗前和台灯周围是亮的，房间其他地方是暗的"）；人可以是剪影 |
| 中景 | 光源和人的关系（"灯在她身后""她站在窗边的光里"），背景比人暗一档 |
| 近景 / 特写 | 脸上的明暗（"朝窗的半边脸亮"），以及眼睛里有没有光 |
| 插入特写（手、物） | 光的颜色落在物体上（"冷蓝的光落在她的手上"） |

## 连续性（同一场戏的多个镜头）

- 一场戏写**一段**灯光文字，所有镜头原样复用，只改景别那一句。
- 不在中途换光源、换冷暖，除非剧情里光真的发生了变化（开灯、天亮）。
- **实测（第二轮）**：同一段灯光文字分别配全景、中景、近景、手部特写，四条的主光方向（窗在左）、冷暖（偏冷）、明暗（偏暗）都一致，没有穿帮。全景里能看到的远处暖灯，在近景里消失但不影响整体冷暖。

- **验收（短剧《钥匙》）**：同一场的中景和近景，冷暖和明暗连上了，但近景的主光方向反了。所以**近景、特写必须加一句方向锚点**，写清哪半边脸亮。
