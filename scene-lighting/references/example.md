# 完整示例：短剧《钥匙》

下面是剧本、按本 skill 拆出的灯光卡和镜头正文，以及在 PX Show（Seedance 2.5 · 480p）上的验收结果。


## 一、剧本

林晚，二十七岁，一个人在城里租房。这一天她被裁员，晚上门外传来钥匙声。

### 第 1 场 · 写字楼茶水间 · 白天 · 内
主管把一个牛皮纸信封放在桌上，转身走了。林晚坐在塑料椅上，没有打开信封，只是盯着它。窗外是阴天，楼下车流无声。
- 剧情功能：压抑 / 冷漠

### 第 2 场 · 便利店门口 · 雨夜 · 外
她抱着纸箱站在便利店的雨棚下，没带伞。店里的白光照在她背上，街上的路灯和车灯在积水里晃。她看着雨，没有走。
- 剧情功能：孤独 / 失落

### 第 3 场 · 出租屋客厅 · 深夜 · 内（两个镜头）
屋里没开灯。门外传来钥匙插进锁孔的声音，锁芯转了半圈。她从沙发上站起来，屏住呼吸盯着门。
- 3A 中景：她站起来，盯着门口。
- 3B 近景：她的脸，呼吸很轻。
- 剧情功能：紧张 / 悬疑

### 第 4 场 · 出租屋客厅 · 深夜 · 内
门开了，是妈妈，手里拎着一袋橘子。林晚按亮台灯，屋里一下子变暖。妈妈什么都没问，只说"吃饭了没"。
- 剧情功能：温暖 / 亲密（光是事件：开灯）

### 第 5 场 · 老家院子 · 午后 · 外（回忆）
小时候的林晚坐在院子的小板凳上剥橘子，妈妈在晾衣服，阳光很亮。
- 剧情功能：回忆 / 如梦

### 第 6 场 · 出租屋阳台 · 清晨 · 外
林晚站在阳台上，手里拿着那个没拆的信封。天刚亮，第一缕阳光照到她脸上，她把信封撕开。
- 剧情功能：转折 / 希望（光是事件：日出）


## 二、灯光卡与镜头正文

### 第 1 场 · 写字楼茶水间 · 白天 · 内

- **剧情功能**：压抑 / 冷漠
- **光源清单**：头顶日光灯管（主）；窗外阴天的灰白天光（辅）
- **灯光段落**（本场所有镜头原样复用）：白天，阴天。茶水间头顶亮着一排青白色的日光灯管，从头顶平平地照下来，几乎没有影子；窗外是灰白的阴天。画面发灰发青，没有一点暖色。

#### 镜头 1

```
中景，固定机位，竖屏。@林晚 坐在茶水间的塑料椅上，面前的桌上放着一个牛皮纸信封。白天，阴天。茶水间头顶亮着一排青白色的日光灯管，从头顶平平地照下来，几乎没有影子；窗外是灰白的阴天。画面发灰发青，没有一点暖色。35mm 定焦镜头，轻微胶片颗粒，肤色真实不磨皮。无对白，无背景音乐，无字幕。
0–4 秒：她一动不动地盯着信封。
4–8 秒：她伸手碰了一下信封，又把手收回来。
8–10 秒：她低下头。
声音：日光灯轻微的电流嗡嗡声，远处打印机的声音。
```

### 第 2 场 · 便利店门口 · 雨夜 · 外

- **剧情功能**：孤独 / 失落
- **光源清单**：便利店里透出的冷白光（主，在她身后）；街上路灯和车灯在积水里的倒影（辅）
- **灯光段落**（本场所有镜头原样复用）：夜里，下着雨。她身后便利店的玻璃门里透出冷白的光，照亮她的后背和肩膀边缘，她的脸是暗的；面前的街上很暗，只有远处一盏路灯和驶过的车灯在积水里晃。整体偏暗、偏冷。

#### 镜头 2

```
中景，固定机位，竖屏。@林晚 抱着一个纸箱，站在便利店门口的雨棚下，面朝街道。夜里，下着雨。她身后便利店的玻璃门里透出冷白的光，照亮她的后背和肩膀边缘，她的脸是暗的；面前的街上很暗，只有远处一盏路灯和驶过的车灯在积水里晃。整体偏暗、偏冷。35mm 定焦镜头，轻微胶片颗粒，肤色真实不磨皮。无对白，无背景音乐，无字幕。
0–4 秒：她看着雨，一动不动。
4–8 秒：一辆车开过，车灯从她脸上扫过又消失。
8–10 秒：她把纸箱抱紧了一点。
声音：雨声，雨点打在雨棚上，车轮压过积水。
```

### 第 3 场 · 出租屋客厅 · 深夜 · 内

- **剧情功能**：紧张 / 悬疑
- **光源清单**：窗外路灯的冷白光（主，从左边窗户进来）；门缝下楼道的一线暖光（辅）
- **灯光段落**（本场所有镜头原样复用）：深夜，屋里没有开灯。画面左边的窗户透进路灯冷白的光，是屋里唯一的主光，在她身后的墙上清楚地投出她的影子；门缝底下透进一线楼道的暖黄光。屋里大部分是暗的，暗部几乎全黑。

#### 镜头 3A

```
中景，固定机位，竖屏。@林晚 在 @老旧出租屋客厅 里，从沙发上站起来，面朝门口。深夜，屋里没有开灯。画面左边的窗户透进路灯冷白的光，是屋里唯一的主光，在她身后的墙上清楚地投出她的影子；门缝底下透进一线楼道的暖黄光。屋里大部分是暗的，暗部几乎全黑。35mm 定焦镜头，轻微胶片颗粒，肤色真实不磨皮。无对白，无背景音乐，无字幕。
0–3 秒：她坐在沙发上，一动不动。
3–7 秒：门外传来钥匙插进锁孔的声音，锁芯转了半圈；她慢慢站起来，盯着门口。
7–10 秒：她屏住呼吸，站在原地。
声音：3 秒时门外钥匙插进锁孔的金属摩擦声，锁芯转动；之后屋里安静。
```

#### 镜头 3B

```
近景，只拍她的脸和肩膀，固定机位，竖屏。@林晚 在 @老旧出租屋客厅 里，面朝门口。深夜，屋里没有开灯。画面左边的窗户透进路灯冷白的光，是屋里唯一的主光，在她身后的墙上清楚地投出她的影子；门缝底下透进一线楼道的暖黄光。屋里大部分是暗的，暗部几乎全黑。35mm 定焦镜头，轻微胶片颗粒，肤色真实不磨皮。无对白，无背景音乐，无字幕。
0–3 秒：她盯着门口，一动不动。
3–7 秒：门外传来锁芯转动的声音，她的喉咙动了一下。
7–10 秒：她屏住呼吸，眼睛一直没离开门口。
声音：3 秒时门外锁芯转动的声音；之后屋里安静。
```

### 第 4 场 · 出租屋客厅 · 深夜 · 内

- **剧情功能**：温暖 / 亲密（光是事件：开灯）
- **光源清单**：开灯前：窗外路灯冷白光；开灯后：她身边的暖黄台灯（主）
- **灯光段落**（本场所有镜头原样复用）：深夜。一开始屋里是暗的，只有窗外冷白的路灯光；4 秒时她按亮身边的暖黄台灯，屋里一下子变暖变亮，台灯就在画面右边。

#### 镜头 4

```
中景，固定机位，竖屏。@林晚 在 @老旧出租屋客厅 里，门口站着一位五十多岁、拎着一袋橘子的女人。深夜。一开始屋里是暗的，只有窗外冷白的路灯光；4 秒时她按亮身边的暖黄台灯，屋里一下子变暖变亮，台灯就在画面右边。35mm 定焦镜头，轻微胶片颗粒，肤色真实不磨皮。无对白，无背景音乐，无字幕。
0–4 秒：门开着，女人站在门口，林晚愣愣地看着她。
4–7 秒：林晚伸手按亮台灯，屋里变暖；女人走进来，把橘子放在桌上。
7–10 秒：女人看着她，轻轻笑了一下。
声音：台灯开关咔哒一声，塑料袋窸窣声；屋里安静。
```

### 第 5 场 · 老家院子 · 午后 · 外（回忆）

- **剧情功能**：回忆 / 如梦
- **光源清单**：午后的阳光（主，在人物身后，逆光）
- **灯光段落**（本场所有镜头原样复用）：午后，阳光很好。太阳在她们身后，院子里亮得几乎发白，人物的脸比背景暗，头发和肩膀的边缘有一圈被阳光照亮的亮边；画面整体很亮、偏暖、有点褪色，暗部也是亮的。

#### 镜头 5

```
全景，固定机位，竖屏。老家的院子里，一个八九岁的小女孩坐在小板凳上剥橘子，旁边一位年轻的母亲在晾衣服。午后，阳光很好。太阳在她们身后，院子里亮得几乎发白，人物的脸比背景暗，头发和肩膀的边缘有一圈被阳光照亮的亮边；画面整体很亮、偏暖、有点褪色，暗部也是亮的。35mm 定焦镜头，轻微胶片颗粒，肤色真实不磨皮。无对白，无背景音乐，无字幕。
0–4 秒：小女孩低头剥橘子。
4–8 秒：母亲抖开一件白衬衫，挂到晾衣绳上。
8–10 秒：小女孩抬头，把一瓣橘子递给母亲。
声音：鸟叫，衣服抖开的声音，远处的人声。
```

### 第 6 场 · 出租屋阳台 · 清晨 · 外

- **剧情功能**：转折 / 希望（光是事件：日出）
- **光源清单**：开始：清晨冷蓝的天光；5 秒后：第一缕暖金色的阳光（主）
- **灯光段落**（本场所有镜头原样复用）：清晨。一开始阳台上是冷蓝色的暗，天刚亮；5 秒时第一缕暖金色的阳光从画面左边照过来，慢慢照到她的脸上，画面从冷变暖。

#### 镜头 6

```
中景，固定机位，竖屏。@林晚 站在出租屋的阳台上，手里拿着一个没拆的牛皮纸信封。清晨。一开始阳台上是冷蓝色的暗，天刚亮；5 秒时第一缕暖金色的阳光从画面左边照过来，慢慢照到她的脸上，画面从冷变暖。35mm 定焦镜头，轻微胶片颗粒，肤色真实不磨皮。无对白，无背景音乐，无字幕。
0–5 秒：她看着手里的信封。
5–8 秒：阳光照到她脸上，她抬起头，眯了一下眼睛。
8–10 秒：她把信封撕开。
声音：清晨的鸟叫，远处的车声，信封撕开的声音。
```
