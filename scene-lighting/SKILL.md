# 剧本灯光设计（scene-lighting）

> v1.0 · 2026-10-25 · 规则来自「不完美，才真实」灯光篇两轮实测（20 条）+ 短剧剧本验收（7 个镜头，6/7 合格）。Seedance 2.5 / PX Show 参考生视频。
> 完整的实测数据和测光记录见 `references/moods.md`、`references/shots.md`、`references/example.md`。

**核心原则：写光源，不写风格词。**
实测：只写"电影感布光"和堆一串"伦勃朗光、体积光、8K"，出来是同一套明亮、偏暖、哪儿都照好的默认光。写清楚"有什么光源、什么颜色、整体多亮"，8 种情绪的光能被明显区分。

## 一、铁律

1. **光必须有出处。** 先列出这场戏里合理存在的光源（窗、灯、屏幕、霓虹、火、车灯），主光从其中一个来。
2. **只写模型认的三件事：光源种类、颜色、整体明暗。** 这三件事执行得最稳。
3. **方向、逆光、轮廓光、投影不要用术语写**（"右前方""逆光""轮廓光"实测不执行），改用第三节的写法：让光源入画、写曝光关系、写实景灯、把影子写到墙上。
4. **同一场戏，光源清单和冷暖不变**；镜头之间只改景别，灯光段落原样复用。**近景和特写再加一句方向锚点**（"光从她左边脸照过来，右边脸在暗里"），否则主光方向可能左右跳（验收 3B）。
5. **光可以是事件**：光随剧情变化（天亮、开灯、门缝漏光）实测能执行，写清"在哪一秒、从什么变成什么"。

## 二、工作流（拆剧本时，每场戏一次）

1. **场景条件** → 时间（清晨 / 白天 / 傍晚 / 夜 / 深夜）、内外景、天气；列光源清单。
2. **剧情功能** → 这场戏要观众感受到什么，从 `references/moods.md` 选一行（温暖、孤独、紧张、危险、浪漫、回忆、压抑、转折）。
3. **写灯光段落** → 用该行的"提示词模板"，替换成本场的光源；放进 PX Show 的 `style_description`（全片共用的质感）之后、每个视频单元正文的开头。
4. **镜头适配** → 按 `references/shots.md` 微调：远景写光池和暗区，近景写脸上明暗。
5. **段落弧线** → 剧情转折处写光的变化（第五条铁律）。
6. **审片** → 看三件事：光源对不对、冷暖对不对、整体明暗对不对；方向和投影不达标时，换第三节的写法重生成，或在分镜首帧里先画好。

## 三、难执行的参数怎么写（第二轮实测）

| 想要 | 不要写 | 这样写 | 实测 |
|---|---|---|---|
| 光从某一侧来 | "光从右前方照过来""侧光" | 让光源入画："画面右侧入画一盏落地灯，是唯一的光" | ✅ |
| 逆光 | "逆光" | 写曝光关系："窗外非常亮、几乎发白，她的脸暗很多" | ✅ |
| 轮廓光 | "轮廓光" | 写实景灯："她身后斜后方一盏台灯，只照亮头发边缘和肩膀" | ✅ |
| 窗格 / 树影投影 | "墙上有窗框影子" | "夕阳低低地直射进来，窗格的影子一格一格印在墙上" | ✅ 印在墙上，不一定印在人身上 |
| 人物投影 | "侧光" | "墙上清楚地投出她的影子，影子比她还大" | ⚠️ 影子会出现，但左右可能反 |
| 硬光 | "硬光、强对比" | "一只没有灯罩的裸灯泡" | ⚠️ 光源会出现、画面变暗，脸上的硬影子做不出 |

**投影写成"墙上 / 地上的东西"能出来，写成"脸上的影子边缘"出不来。** 硬度做不出来时，用暗部比例（"暗部几乎全黑"）代替。

## 四、输出格式：灯光卡

拆剧本时，每场戏输出一张卡，再把灯光段落拼进每个镜头的正文：

```
第 N 场 · 地点 · 时间 · 内/外
- 剧情功能：（moods.md 的一行；光是事件时注明）
- 光源清单：主光（在画面哪边）；辅助光
- 灯光段落：（本场所有镜头原样复用）
- 镜头：景别一句 + 灯光段落 + （近景/特写的方向锚点）+ 动作时间线 + 声音
```

完整示例见 `references/example.md`（原创短剧《钥匙》6 场 7 个镜头，实测 6/7 合格）。

## 六、和其他 skill 的分工

- `pxshow-director`：剧作、分镜、表演、调色（LOOK）。
- `imperfect-camera`：镜头怎么动。
- `scene-lighting`（本 skill）：光怎么打。三者在拆剧本时一起用：先定剧情功能，再分别出镜头和光。
