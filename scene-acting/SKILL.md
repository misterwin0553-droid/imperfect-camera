# 剧本表演设计（scene-acting）

> v0.2 · 2026-10-26 · 规则来自「不完美，才真实」表演篇三轮实测（单人 10 条 + 复测与补救 12 条 + 两人戏 5 条）+ 短剧剧本验收（6 个镜头：v0.1 合格 3、部分合格 3；按 v0.2 改写 3 镜后 6/6 合格）。Seedance 2.5 / PX Show 参考生视频，480p。
> 完整的实测数据（逐条结果、接话间隔、验收记录）见 `references/phrasings.md`、`references/shots.md`、`references/example.md`。

**核心原则：写看得见的部位和结构，不写情绪和修饰语。**
实测：三段都写情绪词（"惊喜和期待的表情""表情很难过"），每个词都被演成满格表情，一个接一个切换；写"嘴唇微张、屏住呼吸、咽一下、视线落到地板"，三次全部照做，而且克制、像真人。模型认**具体的身体部位、视线落点、画面里的人和物、台词的结构**；不认**情绪词、幅度词、时间词、抽象否定**。

## 一、铁律

1. **情绪写成身体部位的变化。** 一段写 2–3 个：嘴、喉咙、视线落点、手。不写"难过""失望""期待"。
2. **不写幅度词。** "克制""幅度很小""几乎看不出来"不会变成细腻，只会把情绪变成零（实测她一直在笑）。想要收着演，就少写、写小部位。
3. **不写时间词。** 一句之内的"过一秒""慢慢地""停一下"会被忽略，或者把整个动作吞掉（实测"先没动，过一秒才转头"→ 她根本没转过来）。时间感靠第四节的结构写法。
4. **视线要有落点，落点要入画。** 只写"看向门口"，人物会直视镜头（单人时 7/10–9/10）。让门框、对方的肩或人出现在画面一侧，再写"看向画面左边的门"（2/2 不看镜头；两人戏对方入画 5/5）。
5. **结尾写留下的姿势和视线，不写否定句。** "没有恢复平静"会被理解成越演越激动；"仍然看着门，手还捏着窗帘，一直保持这个姿势到结束"能留住。
6. **只写这个景别看得见的部位。** 中近景看不到脚（"迈半步"三次都没出来）；双人中景里脸只有几十个像素，嘴和喉咙一级的写法全部失效。详见 `references/shots.md`。
7. **一段只放一个动作，结尾那段只放一个状态。** 一段里串两个小动作，后一个常常丢（验收："低头看钥匙，又抬眼看她"只做了低头；"都不说话……她把视线移开"没移开）。要转视线、再看回来，就各给一段时间（复验：拆开后两处丢掉的动作都做出来了）。

## 二、工作流（拆剧本时，每个镜头一次）

1. **节拍** → 这个镜头里人物经历什么：触发（刚发生了什么）→ 顶点 → 结尾留下什么。10 秒一个镜头，最多一次情绪转变。
2. **景别** → 先定景别，再按 `references/shots.md` 决定能写到哪一级（头和视线 / 脸 / 嘴和眼）。
3. **落点** → 人物看谁、看什么；那个人或物要在画面里露出一部分，写清在画面哪一侧。
4. **写表演段落** → 按时间线分段（0–3 秒 / 3–5 秒……），每段只写动作和部位，用 `references/phrasings.md` 的写法替换情绪词。
5. **两人戏** → 写听者轨（他说话时她身上哪里在变）和接话结构（正常接 / 迟接 / 打断），见第四节。
6. **审片** → 看三件事：情绪有没有演成满格表情、有没有直视镜头、结尾有没有归零；不达标时只改那一段，重生成。

## 三、难演的东西怎么写（实测）

| 想要 | 不要写 | 这样写 | 实测 |
|---|---|---|---|
| 失望、难过 | "露出失望的表情""很难过" | "嘴唇微微张着，屏住呼吸；过了一会儿，她咽了一下，视线从门上落到地板" | ✅ 3/3 |
| 强颜欢笑、表情不对称 | "苦笑""勉强笑了笑" | "一侧嘴角先往上提了一下，像是要笑，随即压了回去；眼睛一直没有笑" | ✅ 女演员 2/3 明显；男演员 1 次只有很淡的一下。力度会飘，别当关键节拍 |
| 听者被一句话刺中 | "她听了很难过" | 给听者单独一个近景，写一个嘴部动作 + 视线："听到'衬衫'时，她嘴唇压紧；随后视线落到他手里的钥匙" | ✅ 近景里看得清；写两个嘴部动作会演过（含泪），只写一个后收住了 |
| 收着演 | "克制地流露出一点失望，幅度很小" | 少写，只写小部位（同第一行）；或这一段只写动作、不写任何情绪词 | ❌ 幅度词把情绪变成零 |
| 反应慢半拍 | "先没动，过了一秒才转头" | "她搭在窗帘上的手指先停住，然后肩膀转过来，最后才转头看向门口" | ⚠️ 1/2 变慢；"过一秒"的写法 0/1，动作被吞掉 |
| 不看镜头 | "看向门口" | 开头写"画面左边能看到门框的一角"，动作写"看向画面左边的门" | ✅ 2/2 |
| 结尾不归零 | "没有低头，也没有恢复平静" | "她仍然看着门，手还捏着窗帘，一直保持这个姿势到结束" | ✅ 1 条完全做到，1 条最后略垂眼；不再越演越激动 |
| 内心戏 | 只写想法："她想说服自己那只是邻居" | 尽量换成部位写法；只写想法时模型会自己编一段戏 | ⚠️ 好看但不可控 |
| 台词说得轻、慢 | "停了一秒，才很轻、很慢地说" | 写说完之后脸上留下的状态："说完嘴没有合上，等着门外回答" | 句内停顿和语速 ❌；说完的状态 ✅ |

## 四、两人戏

**接话节奏写结构，不写语速。**

| 接法 | 这样写 | 实测（他最后一个字 → 她开口） |
|---|---|---|
| 正常接 | 分段写，回答放进下一段时间："6–10 秒：他说完，林晚回答：……" | 3.2 秒。分段本身就会把回答推后，不会两人匀速轮流 |
| 迟接 | 给沉默单独写一段并写这段里身上发生什么："他说完，屋里静了下来。林晚看着他，咽了一下，才很轻地说：……" | ✅ 5.3 秒，2/2（试点 + 验收），沉默里她低着头或看着钥匙，不是卡住 |
| 打断 | 把对方的台词写成残句并写"打断"："陈默说：'我回来拿点东西，拿完就——' 话还没说完，林晚就打断他：'知道了。'" | ✅ 0.0 秒，2/2，他的话真的断在残句处 |

**听者反应按景别写。** 双人中景只写头、视线、手（"视线从他脸上落到他手里的钥匙"能看出来）；嘴和喉咙一级的反应（"嘴唇张开像要说什么，又合上"）在双人中景里看不见，要给听者单独一个近景（验收实测有效，见第三节）。

**画外台词会冒出字幕。** 听者近景里只有画外的一句话时，画面烧进了台词字幕，正文写了"无字幕"也没用；两人都在画面里说话时没有出现。画外台词的镜头要逐条检查字幕，有就重生成（同样的正文重跑一次就没有了，是随机的）。

**站位不可靠。** "站在门口，没有进屋"合计 7 条里只有 3 条照做；位置重要时，用参考图或首帧定死。台词分配没有出过错：他的话是男声，她的话是女声。

## 五、输出格式：表演卡

拆剧本时，每个镜头输出一张卡，再把表演段落拼进镜头正文（灯光段落放在前面，见 scene-lighting）：

```
镜头 N · 景别 · 时长
- 节拍：触发 → 顶点 → 结尾留下什么
- 落点：人物看谁 / 看什么，它在画面哪一侧（入画写法）
- 能演到哪一级：头和视线 / 脸 / 嘴和眼（shots.md）
- 表演段落：分秒时间线，只写动作和部位
- 两人戏：听者轨 + 接法（正常 / 迟接 / 打断）
```

完整示例见 `references/example.md`：原创短剧《备用钥匙》6 个镜头的表演卡和正文，附逐镜验收结果。

## 七、和其他 skill 的分工

- `pxshow-director`（如果你有）：剧作、分镜、调色（LOOK）。表演的完整方法论（目的、动词、地位、语速预算）讲的是演员该怎么想；本 skill 只收**实测过、确认模型会执行的写法**，两者冲突时以本 skill 为准。
- `imperfect-camera`：镜头怎么动。
- `scene-lighting`：光怎么打。
- `scene-acting`（本 skill）：人怎么演。拆剧本时先定剧情功能，再分别出镜头、光和表演。
