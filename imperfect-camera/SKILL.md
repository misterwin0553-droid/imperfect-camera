# 不完美，才真实 · 导演运镜（imperfect-camera）

> v0.3 · 2026-10-24 · 已并入实测经验（见第五节）。核心思路：用"不完美"思维指导运镜，是让 AI 视频更真实的有效路径。

**用户选导演，skill 做翻译，PX Show 收到的是行为。**

```
用户：「用姜文的风格拍」
   ↓  directors/jiang-wen.md
skill：参与型拍摄者 · 情绪先于事件 · 广角仰拍 · 得意时绕行
   ↓  穿透
PX Show：style_description 追加句 + image_prompt 构图 + camera_motion 枚举 + action 里的拍摄者行为
```

为什么不直接写"姜文风格"：模型对一个名字的理解是这位导演所有作品的**平均**，通常只学到色调和题材，学不到拍法（均值坍缩，见 `references/theory.md`）。真正让镜头像真人拍的，是**有原因的偏差**——这正是本 skill 负责翻译的部分。

## 一、铁律

1. **名字不进提示词。** 用户看到导演名，PX Show 只看到行为描述。例外：PX Show 内置风格模板（如 `live_wong`）可以选，它只管 LOOK。
2. **没有原因的偏差就是噪声。** 每个偏差都来自导演卡里的参数，能说出是哪一层（物理 / 感知 / 作者 / 现场 / 情绪）、服务什么戏剧功能。
3. **描述拍摄者，不描述运镜结果。** ❌ "smooth push in" → ✅ "镜头比她先激动起来，猛地往前一冲"。
4. **意图准确，执行有痕。** 关键事件可以拍晚、拍偏、被遮挡，不能拍丢。
5. **一部片一位导演。** 不混搭；混搭会让偏差方向互相抵消，回到平均。

## 〇、两种模式

| 模式 | 什么时候用 | 产出 |
|---|---|---|
| **PX Show 模式** | 用户在 PX Show 上做片（有 pxshow-director 时叠加在它之上） | 按第二节写进 PX Show 各字段 |
| **通用模式** | 用其他视频模型（Seedance、可灵、即梦、Veo、Sora 等），或只想要一段提示词 | 一段可直接粘贴的提示词，**同时给基线版和导演版**，方便对比 |

### 通用模式流程
1. 选导演（同第二节步骤 1）。
2. 先写一版**基线镜头**：谁、在哪、发生什么、镜头平稳地怎么拍、停在哪里。这是"理想执行"，偏差施加在它之上。
3. 按导演卡改写成一段提示词，顺序固定：
   `[画面质感：导演卡 3.1 追加句 + LOOK 协同] → [开场构图：3.2] → [时间线：人物动作 ↔ 拍摄者反应交错，用 3.3 句式] → [镜头最终怎么停] → [声音]`
4. 时长 ≥8 秒时用三段式：`0–3 秒 等待（镜头静止）→ 3–7 秒 刺激与拍摄者反应 → 7–10 秒 余波（镜头保持刚才的状态）`。不写满的时间，模型会自己补"标准答案"式的平稳运镜。
5. 第一节铁律、第五节实测约束同样适用；导演名字依然不进提示词。

## 二、工作流（PX Show 模式；有 pxshow-director 时叠加在其阶段 0–5 之上）

### 步骤 1：让用户选导演（立项时）
- 给用户看 `references/directors/index.md` 第一张菜单表（名字、代表作、一句话气质、适合题材）。**不展示参数。**
- 用户说不出名字时，按菜单下的"用户说 → 推荐"表推荐。
- 导演有多个时期（如王家卫手持期 / 花样年华期）时，让用户再选一次。
- 剧本题材与导演气质明显冲突时，先说明，再按用户选择执行。
- 若该导演的卡片标记为"待写"，先按 `directors/_template.md` 补全卡片，再开工。

### 步骤 2：全局穿透
从导演卡第 3.1 节取：
- **style_description 追加句** → 追加到 pxshow-director 写好的 LOOK 之后。
- **LOOK 协同** → 告诉 pxshow-director 选哪个内置风格模板、调色方向。
- **景别分布 / camera_motion 偏好** → 作为分镜审定时的约束。

### 步骤 3：逐镜标注
在 pxshow-director 的镜头卡后加四列：`场景类型 | 强度(1–5) | 戏剧功能 | 偏差条目`。
- 场景类型从导演卡 3.3 节的五类里选：对话文戏 / 突发事件 / 行走跟随 / 情绪高点 / 余波结尾。
- 偏差条目**优先取该行推荐**，每镜最多 2 条；不得使用导演卡 3.4 节的禁用条目。

### 步骤 4：首帧穿透（storyboard 模式，最可控）
用导演卡 3.2 节的构图模板写 `image_prompt.scene` / `composition.blocking`。静帧审片时检查：偏差像**这位导演的选择**，还是像**生成错误**。

### 步骤 5：视频穿透
- `camera_motion`：按导演卡偏好选枚举，禁用的不选。
- `video_prompt.action`：用导演卡 3.3 节的拍摄者句式，与人物动作交错写：
  `人物动作 → 拍摄者反应/心情 → 人物变化 → 镜头落定`
- 句式细节见 `references/pxshow-mapping.md`，偏差定义见 `references/deviation-catalog.md`。

### 步骤 6：后期（可选）
模型做不到的（抽帧拖影、动作中途切入、不规整时长）交给剪辑与 ffmpeg，见 deviation-catalog 的 E 系列。

### 步骤 7：审片——风格三问
1. **像这位导演吗？** 熟悉这位导演的人能认出来吗？认不出 = 偏差没执行或剂量不够。
2. **看得出原因吗？** 能感到拍摄者在反应什么、或此刻什么心情？看不出 = 噪声 / AI 炫技。
3. **关键信息丢了吗？** 丢了 = 越过红线，重做。
另外区分 **模型未执行**（改通道：首帧 / 参考视频 / 后期）与 **执行但很假**（降剂量）。

## 四、纪律
- 先有理想执行（pxshow-director 的镜头卡，或通用模式的基线版），再按导演卡施加偏差。
- 每镜最多 2 条偏差；不确定剂量时取低一档。
- 只报告看到的：提示词里写了 ≠ 视频里出现了。

## 五、实测经验（Seedance 2.5 · 10 秒 · 每种写法生成 2 次）

以下是实际生成中观察到的规律，写法以此为准。

1. **S1 晚半拍跟随：2/2 执行**，两次轨迹几乎一致。注意：基线版也是"人先动、镜头后动"，S1 的区别在于镜头**在人物动作过程中就开始追**，而不是等动作结束再从容推过去。写的时候要写出"追"。
2. **模型有很强的"镜头回应事件"习惯**：镜头总在回应画面里已经发生的事。
   | 偏差 | 与模型习惯 | 难度 | 怎么写 |
   |---|---|---|---|
   | 晚半拍、追赶、找人、被画外吸引（L1/L2） | 同向 | 容易 | 正常写 |
   | 抢先、预判（M1、S2） | 反向 | 难（M1 实测 0/2） | 用时间戳钉住顺序，或给镜头一个画内触发物；仍不行就换通道（参考视频 / 后期） |
3. **L5 情绪层三条约束**（M 系列必须同时满足）：
   - **锁表演**：拍摄者的情绪会传染给演员。写"镜头紧张"时，加一句"她的反应和平时一样，只是镜头紧张"。
   - **限幅度**：幅度过大会被执行成跳切。写"猛地往前冲了一两步"，不写"一冲到她脸前"。
   - **钉时间**：要抢先就写时间戳，例如"3.0 秒镜头先往前冲；3.8 秒她才转身"。
4. 参考生视频（无共用首帧）时起幅不受控，对比不同写法时先看 0–3 秒的起幅是否一致。
