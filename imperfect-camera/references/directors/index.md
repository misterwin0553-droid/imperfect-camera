### 用户说不出导演名时
问用户想要的感觉，按下表推荐：

| 用户说 | 推荐 |
|---|---|
| "像纪录片""真实""手持" | 达内兄弟 / 宁浩 |
| "高级""文艺""安静" | 侯孝贤 / 是枝裕和 |
| "暧昧""港风""氛围" | 王家卫 |
| "燃""狂""有劲" | 姜文 |
| "好笑但不傻" | 宁浩 |
| "紧张刺激" | 格林格拉斯 / 达内兄弟 |

### 规则
- **一部片一位导演**。不支持混搭（混搭会把偏差方向抵消，回到平均值）。
- 剧本题材与导演气质冲突时（如用侯孝贤拍打斗），先告诉用户，再执行用户的选择。

## 二、内部参数定义（skill 自用）

| 参数 | 含义 | 取值 |
|---|---|---|
| 参与度 | 拍摄者与事件的关系（总轴） | 旁观 / 跟随 / 参与 |
| 器材 | L1 物理签名 | 三脚架 / 轨道 / 斯坦尼康 / 摇臂 / 稳定器 / 肩扛 / 手持 |
| 反应延迟 | S1 幅度 | 负（抢先）/ 0 / 半拍 / 一拍 / 拒绝跟随 |
| 惯性 | P1/P2 幅度 | 轻 / 中 / 重 |
| 预知对齐 | 镜头的知识和谁对齐 | 无 / 角色 / 观众 / 导演-主观 / ~~导演-客观~~（AI 默认，禁用） |
| 情绪基调 | L5 拍摄者情绪 | 冷漠 / 好奇 / 紧张 / 亢奋 / 得意 / 迷恋 / 恐惧 |
| 构图偏置 | L3 固定选择 | — |
| 好奇心 | S3/S4 频率 | 低 / 中 / 高 |
| 耐心 | A4 停留倾向 | 剪得早 / 正常 / 停得久 |
| 基础剂量 | 全片偏差总量 | 低 / 中 / 高 |
| 戏剧功能偏好 | 偏差主要服务的功能 | 真实 / 紧张 / 喜剧 / 亲密 / 疏离 / 主观 |
