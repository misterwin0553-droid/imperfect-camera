# 埃曼努尔·卢贝兹基

## 1. 用户可见
- **名称**：埃曼努尔·卢贝兹基（摄影师；合作导演马力克、伊纳里图、卡隆）
- **代表作**：《人类之子》《生命之树》《鸟人》《荒野猎人》
- **一句话气质**：镜头像一个好奇的灵魂，贴得很近、一直在漂浮，会离开人去看树、看光，再回来。
- **适合题材**：诗意、自然、生存、记忆、灵性
- **不太适合**：快节奏喜剧、对话密集的室内戏
- **可选时期/变体**：
  - **漂浮诗意版**（默认，《生命之树》）：自然光、魔幻时刻、镜头游走
  - **长镜头沉浸版**（《鸟人》《荒野猎人》《人类之子》）：一镜到底、广角贴脸、身体性强（呼吸起雾、血溅镜头）

## 3. 穿透配方

### 3.1 全局
- **style_description 追加句**："超广角镜头贴近人物，像一个好奇的灵魂在她身边漂浮，不停地缓慢移动；常常离开人物去看树叶、光线和天空，再慢慢回到她身上；只用自然光，偏爱黄昏和清晨的低角度阳光。"
- **LOOK 协同**：纯自然光、魔幻时刻、低反差、高动态范围、天空不过曝；冷暖随时间自然变化。
- **景别分布**：广角 Medium Close-up 约 40%（贴近但带环境），Medium Shot 约 30%，环境与天空的游走约 30%。
- **camera_motion**：常用 Tracking Shot、Orbit（慢、漂浮）、Pedestal Up（仰向天空）、Truck；慎用 Static；禁用 Zoom、Shake。
- **剪辑节奏**：长镜头或省略式跳切（《生命之树》）；时间感像记忆。

### 3.2 首帧构图（image_prompt）
- "超广角从她身侧低处仰拍，她的脸占画面一侧，头顶是逆光的树冠和天空。"
- "镜头离她不到一米，广角把背后的田野拉得很远很开阔，夕阳在她肩后。"
- "画面里有一部分是她，另一部分是窗外摇动的树叶，两者同样清晰。"

### 3.3 场景类型 → 拍摄者行为
| 场景类型 | 强度 | 戏剧功能 | 偏差 | action 拍摄者句式 |
|---|---|---|---|---|
| 对话文戏 | 2 | 主观 | S3 / S4 | 两人说话时镜头缓慢绕着他们漂浮，中途被窗外的光吸引，飘过去看了一眼，又回到她脸上。 |
| 突发事件 | 4–5 | 主观、紧张 | P（身体性）/ S1 | 他扑倒在雪地里，镜头跟着压低贴近，他喘出的白气扑到镜头上，画面起了一层雾。 |
| 行走/跟随 | 2–3 | 主观 | 漂浮跟随 / S3 | 镜头在她前方倒退漂浮，时而仰起看树冠，时而落回她的脸。 |
| 情绪高点 | 4–5 | 主观 | Pedestal Up / S3 | 她仰起头的瞬间，镜头离开她，缓缓升向天空和穿过树叶的阳光。 |
| 余波/结尾 | 1–2 | 主观 | S4 / 环境 | 镜头从她身上慢慢飘开，停在风中摇动的草上。 |

### 3.4 签名 / 禁用
- **签名**：S3 被环境吸引并回来、超广角贴近、仰拍天空、自然光逆光、身体性物理痕迹（呼吸雾、水滴、血溅镜头）。
- **禁用**：Zoom、Shake、锁死的三脚架、人工补光、A3 拍听者（他总在主角身边）。
- **注意**：游走必须**回来**。离开不回 = 失焦叙事。

## 4. 穿透示例
- shot_type：Medium Close-up（超广角）
- camera_motion：Orbit
- image_prompt 构图：超广角在她身侧低处，她背对镜头站在窗前，窗外是黄昏逆光的树冠，金色的光从树叶缝隙里漏进来，镜头离她不到一米。
- video_prompt.action：她背对镜头站在窗前，镜头在她身侧缓慢漂浮，被窗外摇动的树叶吸引着微微仰起。门外传来钥匙声，镜头从树叶上落回来，绕向她的正面；她猛地转过身，下颌收紧，盯着门口，手指捏住窗帘边。镜头停在她的脸旁，夕阳贴着她的侧脸，仍在极缓慢地漂移。

## 5. 短剧适配与风险
- **9:16**：竖屏适合"人在下、树冠天空在上"的仰拍构图；Orbit 幅度要小。
- **时长**：漂浮与游走需要较长档位（Seedance 2.5）；短档位只能保留"贴近 + 自然光"，游走会被压缩掉。
- **风险**：超广角贴脸易导致脸部变形；游走镜头可能被模型生成为无目的漂移 → 每次游走都写清"被什么吸引"和"回到哪里"。
