# 偏差 → PX Show 字段映射

## 字段分工

| 字段 | 承载哪层 | 写法 |
|---|---|---|
| `style_description` 末尾 | 人格总纲（L3 + 器材 L1） | 一句器材 + 一句拍法，**不写具体运镜**。例："肩扛 35mm 定焦拍摄，摄影师像跟随真实事件的纪录片摄影师，总是晚一步，构图偏紧偏右。" |
| `image_prompt.scene` / `composition.blocking` | L3 构图、L4 现场 | 写机位位置与遮挡："机位在门框外，左侧前景是虚化的门框边，她在画面右三分之一偏外" |
| `composition.shot_type` | — | 照选枚举 |
| `camera_motion` | L1（粗） | 照选最接近的枚举；**偏差不写在这里**。手持感优先 Static/Tracking Shot，避免 Shake |
| `video_prompt.action` | L1、L2 | 人物动作链与拍摄者反应**交错写** |
| `ambiance_audio` | L2 诱因 | 为 S3（画外吸引）提供声源 |
| 参考视频 `@视频1` | L1、L2 | "参考 @视频1 的摄影机运动节奏与手持质感，不参考画面内容" |

## action 交错句式模板

```
[起始] 人物状态。镜头（拍摄者状态：手持/肩扛，停在哪里）。
[刺激] 人物动作。
[拍摄者反应] 镜头 + 偏差条目句式（晚半拍 / 过冲 / 找焦 / 偏向画外）。
[人物变化] 2–3 个可见变化。
[落定] 镜头最终停在哪里，停得怎样（停稳 / 微微晃着停住 / 没完全停稳）。结尾画面。
```

### 示例：S1 + P2，强度 4，剂量中

> 她背对镜头站在窗前。手持镜头停在她身后约两米，轻微随呼吸起伏。
> 门外传来钥匙声，她猛地转身。镜头晚了半拍才跟着往右摇，摇过头一点，又轻轻退回来稳住在她脸上。
> 她下颌收紧，眼睛盯着门口，手指捏住窗帘边。
> 镜头最终停在她的中近景，没有完全停稳，仍有一点手持的微晃。

### 对照：同一镜头的 baseline 写法（pxshow-director 原版）

> 她背对镜头站在窗前。门外传来钥匙声，她猛地转身，下颌收紧，眼睛盯着门口，手指捏住窗帘边。镜头平稳摇向她，停在中近景。

### 对照：随机噪声写法（实验 B 组）

> 同 baseline，并加上：轻微手持晃动。camera_motion = Shake。

## 禁忌
- 不写"不完美""业余""拍坏""失误"这类元描述——模型会生成画质降级。只写**具体的物理行为**。
- 不写"增加晃动""去掉稳定"等编辑类动词（Seedance 2.5 会误判为编辑任务）。
- 一条 action 里拍摄者反应最多 2 处。
