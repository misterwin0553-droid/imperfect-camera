# 安德里亚·阿诺德 / 罗比·瑞恩

## 1. 用户可见
- **名称**：安德里亚·阿诺德（导演）与罗比·瑞恩（摄影）
- **代表作**：《红色之路》《鱼缸》《呼啸山庄》《美国甜心》
- **一句话气质**：镜头贴得很近，拍她的手、头发、皮肤和身边的小虫子，阳光直接扎进镜头。
- **适合题材**：青春、亲密关系、女性成长、自然与身体
- **不太适合**：动作大场面、喜剧、冷峻悬疑
- **可选时期/变体**：
  - **4:3 窄画幅**（默认，《鱼缸》《呼啸山庄》）：画面像被关在人物身边
  - **公路版**（《美国甜心》）：更多车窗、阳光、移动中的身体

## 3. 穿透配方

### 3.1 全局
- **style_description 追加句**："轻手持镜头贴得很近，像在她身边呼吸；常拍她的手、头发、脖子和身边的小细节；自然光，阳光直接照进镜头形成眩光；浅景深，焦点偶尔追不上她。"
- **LOOK 协同**：自然光、暖色阳光、柔和高光溢出、肤色真实带瑕疵；不要磨皮。画幅建议 4:3 或保留竖屏。
- **景别分布**：Close-up / Extreme Close-up（局部）约 50%，Medium Close-up 约 35%，Medium Shot 约 15%。
- **camera_motion**：常用 Static（手持微晃）、Tracking Shot；慎用 Pan；禁用 Orbit、Pedestal、Zoom、平稳 Push In。
- **剪辑节奏**：自然、不规则；常插入一个局部特写（手、虫、光斑）打断叙事。

### 3.2 首帧构图（image_prompt）
- "镜头贴近她的侧脸，额头被画框切掉一点，阳光从她身后打进镜头形成一片暖色眩光。"
- "极近地拍她的手指搭在窗台上，手背上有细小的绒毛，背景完全虚化。"
- "她的头发被风吹乱遮住半张脸，焦点落在发丝上。"

### 3.3 场景类型 → 拍摄者行为
| 场景类型 | 强度 | 戏剧功能 | 偏差 | action 拍摄者句式 |

| 突发事件 | 3–4 | 亲密、紧张 | S1 / P5 | 她突然转头，镜头晚了半拍跟上，焦点慢了一下，她的脸先模糊再清晰。 |

| 情绪高点 | 4 | 亲密 | A5 / P5 | 她哭的时候镜头只拍她攥紧的手和发抖的下巴，焦点在手指上。 |
| 余波/结尾 | 1–2 | 亲密 | S4 | 她安静下来，镜头慢慢移到她的眼睛，阳光在睫毛上闪。 |

### 3.4 签名 / 禁用
- **签名**：A5 拍局部、A2 头顶紧、P5 找焦、阳光眩光、S3 被小细节吸引。
- **禁用**：M1/M2/M5、A1 远距负空间、C4 隔物远拍、任何冷静的远景观察。

## 4. 穿透示例
- shot_type：Close-up
- camera_motion：Static
- image_prompt 构图：镜头贴近她的后颈和侧脸，额头被画框切掉一点，窗外傍晚最后一抹低角度的夕阳从她身前打进镜头，形成一片暖色眩光，她的发丝在光里发亮。
- video_prompt.action：她背对镜头站在窗前，手持镜头贴在她肩边，随呼吸轻轻起伏。门外传来钥匙声，她猛地转过脸，镜头晚了半拍跟上，焦点慢了一下，她的脸先模糊再清晰。她下颌收紧，盯着门口。镜头往下滑到她的手，手指正把窗帘边攥成一团。

## 5. 短剧适配与风险
- **9:16**：竖屏天然适合近距离和局部特写；4:3 风格可用竖屏的左右留黑模拟，或直接用竖屏贴近。
- **时长**：短档位即可，局部插入镜头 1–2 秒。
- **风险**：浅景深找焦易被判画质差；眩光可能盖掉脸部；大量局部特写可能损失人物识别 → 每场至少一个完整脸部镜头。
