# 有因的不完美（Motivated Imperfection）
## AI 视频镜头语言去 AI 感的理论框架 · v0.2

> 核心命题：AI 运镜的"AI 感"不来自完美，而来自**无作者的平均**与**无因果的流畅**。
> 解法不是加噪声，而是给镜头装回一个"有身体、有局限、有偏好、受现场约束、有情绪的拍摄者"。

**v0.2 更新**：新增 L5 情绪层（源自姜文）；感知层新增"预知对齐"（源自宁浩）；新增假设 H7、H8。

---

## 1. 诊断：AI 感从哪里来

把"AI 感运镜"拆成七个可观察、可验证的病因。后面每一条解法都要对应到这里的某一条。

| 编号 | 病因 | 机制 | 画面上的症状 |
|---|---|---|---|
| D1 | **均值坍缩** | 生成模型输出趋向分布众数；美学打分/偏好对齐进一步把输出推向"好看的平均" | 构图永远在安全区，节奏永远舒服，没有任何一个选择让人意外 |
| D2 | **全知视角** | 模型"知道"整条提示词，即知道接下来发生什么 | 镜头在动作发生前就已就位；跟拍零延迟；从不错过、从不找人 |
| D3 | **无质量运动** | 视频扩散的时间平滑先验压制高频运动；轨迹接近理想缓动曲线 | 匀速推轨、完美 ease-in-out、无过冲、无回调、无起步的"顿" |
| D4 | **镜头自足** | 每条生成都是一个完整小单元，被训练成有起有落 | 起幅落幅都静止且规整；镜头从不在动作中途开始或结束 |
| D5 | **全局同时最优** | 每个元素都被单独优化到最好，没有取舍 | 光、焦、构图、表演、动势同时满分——现实中几乎不可能 |
| D6 | **训练数据偏差** | 数据集按美学分数过滤，广告/预告片/图库素材过度代表；"拍坏的帧"被系统性删除 | 商业片质感、图库感；"不完美"在模型里本来就是稀有分布 |
| D7 | **无现场** | 模型的摄影机没有物理位置约束，可以出现在任何地方 | 机位"理想"到不合理：穿墙、悬浮、永远在最佳角度 |

**关键推论**
- D1 + D6 说明：不完美在模型里是**低概率区域**，不会自然出现，必须被**显式召唤**。
- D2 + D3 说明：随机抖动无法解决问题，因为它补的是"高频"，缺的却是"因果"和"延迟"。
- D5 说明：真实感的一部分来自**取舍的痕迹**——为了 A 牺牲了 B。

## 2. 定义：什么是"有因的不完美"

**定义**：镜头相对"理想执行"的偏差 Δ，满足以下四性，则称为有因的不完美：

1. **因果性（Causal）**：每个偏差都能归因于一个具体原因——物理惯性、感知延迟、作者偏好、现场约束或拍摄者情绪。说不出原因的偏差就是噪声。
2. **一致性（Consistent）**：同一个"拍摄者人格"在全片中的偏差方向稳定。风格 = 稳定的偏差。
3. **有界性（Bounded）**：偏差不越过"准确性红线"（见 §4）。
4. **相关性（Correlated）**：偏差的幅度与戏剧强度相关——越突然的事件，越大的延迟和修正；越平静的戏，越接近静止。

形式化地写：

```
实际镜头 = 理想轨迹 + Δ
Δ = f(拍摄者人格, 场景事件, 现场约束)      ← 有因的不完美
Δ ≠ ε ~ N(0, σ²)                          ← 随机噪声（失败的做法）
```

## 3. 五层模型

| 层 | 问题 | 来源 | 可控程度（在 PX Show 里） |
|---|---|---|---|
| **L1 物理层** | 机器和人有重量吗？ | 惯性、呼吸、步伐、对焦机构、镜头光学 | 中（文字描述 + 参考视频 + 后期） |
| **L2 感知层** | 拍摄者知道接下来会发生什么吗？ | 反应延迟、注意力、信息不对称 | 中低（最难，也是最核心） |
| **L3 作者层** | 这是谁拍的？ | 导演/摄影师的稳定偏好 | 高（分镜图构图 + style_description） |
| **L4 现场层** | 摄影机在哪里、受什么限制？ | 空间、遮挡、光源、器材选择 | 高（分镜图 + blocking + continuity） |
| **L5 情绪层** | 拍摄者此刻是什么心情？ | 拍摄者自身的情绪：亢奋、得意、恐惧、迷恋、冷漠 | 中（action 文本 + 剪辑节奏） |

L1–L4 里的拍摄者是**受限的记录者**：偏差来自他"做不到"。L5 里的拍摄者是**有情绪的参与者**：偏差来自他"忍不住"。

**参与度谱系**（贯穿五层的总轴）：

```
旁观 ──────────── 跟随 ──────────── 参与
侯孝贤/小津       达内/宁浩          姜文
不追、不动        追、晚半拍         抢先、亢奋、主观
L3/L4 主导        L1/L2 主导         L5 主导
```

### L1 物理层：重量
- **起止动力学**：起步有"顿"（静摩擦），停止有过冲 → 回调 → 落定。真实的速度曲线**不对称**：加速慢、刹车急，或相反，取决于人格。
- **手持节律**：晃动跟随呼吸（~0.2–0.3 Hz）和步伐（~1.5–2 Hz），有节奏，不是白噪声。肩扛 > 手持稳定器 > 斯坦尼康 > 轨道，各有可识别的"签名"。
- **对焦**：跟焦有滞后；主体快速移动时短暂失焦再找回（focus hunt）；焦点转移有加减速。
- **光学**：镜头呼吸（对焦时视角轻微变化）、边缘畸变、暗角、眩光、色散。

### L2 感知层：信息不对称（最核心）
- **反应延迟**：人类视觉-运动反应约 200–400 ms。演员转身，镜头**晚半拍**跟上。
- **预判失败**：以为人物要往左，镜头先往左动了一点，发现错了，再回来。
- **注意力游离与回收**：被画外声音吸引，镜头偏过去一点，再回到主体。
- **发现式构图**：镜头起初没拍到最好的角度，在拍摄中**逐渐找到**更好的位置。
- **关键原则**：拍摄者的知识状态应该**少于**观众或至多等于角色。纪录片 = 完全不知道；排练过的剧情片 = 大致知道但仍有反应；AI 默认 = 全知。
- **预知对齐**（源自宁浩）：预知度不只有多少，还有"和谁对齐"。

| 对齐对象 | 镜头知道什么 | 戏剧效果 | 例 |
|---|---|---|---|
| 无（纪实） | 什么都不知道 | 真实、紧张 | 达内 |
| 角色 | 只知道镜头前这个角色知道的 | 喜剧（狼狈被撞见）、悬疑（和角色一起被吓到） | 宁浩 |
| 观众 | 知道观众已知的（如画外有危险） | 悬念（希区柯克的"桌下炸弹"） | — |
| 导演（主观全知） | 什么都知道，但带情绪地表达 | 狂想、表现主义 | 姜文 |
| 导演（客观全知） | 什么都知道，平静地表达 | **AI 默认**——无人格的全知 | AI |

AI 的问题不是"全知"本身（姜文也全知），而是**无人格的客观全知**。

### L3 作者层：稳定的偏好
- **构图偏置**：主体系统性偏离中心、头顶空间偏少/偏多、大面积负空间、前景遮挡（脏画面）。
- **时间偏置**：镜头停留比舒适时长更久（让尴尬发酵），或剪得比预期早（不给情绪落地）。
- **关注偏置**：拍说话者 vs 拍听者；拍脸 vs 拍手；在情绪高点拍背影。
- **违规偏好**：有意的越轴、跳切、主体出画、拍不全。
- **原则**：作者层的偏差必须**全片一致**，偶尔一次是失误，一直如此才是风格。

### L4 现场层：约束的痕迹
- 机位受空间限制：狭窄房间里只能用广角、只能贴墙、只能从门框里拍。
- 遮挡：门框、人头、玻璃反光、窗帘、桌上的杯子挡住半个画面。
- 光源取舍：为了保住窗外，脸只能欠曝；为了实景光，接受混合色温。
- **原则**：给每个机位一个"为什么只能放在这里"的理由，画面就会带上现场的痕迹。

### L5 情绪层：拍摄者有心情（源自姜文）
- **情绪先于事件**：拍摄者因为亢奋，镜头比人物先动起来、先冲上去（反应延迟为负）。
- **情绪改写画面**：广角仰拍把人拍得比真实更高大；运动随拍摄者的得意而加速、炫耀；恐惧时镜头后退、不敢靠近。
- **不可靠的镜头**：《阳光灿烂的日子》中，旁白承认记忆不可靠——镜头拍的是被情绪改写过的记忆，不是事实。
- **与 AI 炫技的区别**：AI 也常生成大幅度运动，表面上像姜文。区别在因果：
  - 姜文：大运动 ← 拍摄者的亢奋/得意/调皮（有主人）
  - AI：大运动 ← 提示词要求"dynamic camera"（无主人）
- **原则**：情绪层的运动必须能读出"拍摄者此刻的心情"，且这个心情要和戏剧节拍对应（得意时炫、心虚时躲）。

### 偏差的戏剧功能（源自宁浩 vs 达内对比）
同一条偏差在不同人格、不同语境里承担不同戏剧功能：

| 功能 | 含义 | 例：S6 来不及框全 |
|---|---|---|
| 真实 | 让观众相信"真有人在拍" | 中性纪实 |
| 紧张 | 制造不安、失控 | 达内：追不上 → 焦虑 |
| 喜剧 | 制造信息差、狼狈 | 宁浩：摔倒只拍一半 → 笑 |
| 亲密 | 让观众贴近角色 | 瑞恩：太近拍不全脸 |
| 疏离 | 让观众远离、冷眼 | 侯孝贤：人物出画也不追 |
| 主观 | 让观众进入拍摄者情绪 | 姜文：激动到构图倾斜 |

**选偏差时先定功能，再选条目。**

## 4. 准确性红线：不完美 ≠ 不准确

| 必须准确（红线内） | 允许不完美（红线外） |
|---|---|
| 故事信息：观众必须看到该看到的关键事件 | 时机：可以晚半拍看到 |
| 轴线、视线方向、空间关系 | 构图：可以偏、可以挤、可以被遮挡 |
| 人物身份与连贯 | 平滑度：可以有顿挫、过冲、修正 |
| 情绪的最终落点 | 焦点：可以短暂失焦后找回 |
| 节奏的总体意图 | 起止：可以在动作中途切入/切出 |

一句话：**意图百分百准确，执行带人的痕迹。**关键事件可以拍晚、拍偏、拍得不舒服，但不能拍丢。

## 5. 剂量：不完美的"量"

不完美存在一个倒 U 型曲线：

```
真实感
  ▲          ╭──╮
  │        ╱      ╲
  │      ╱          ╲___ 粗糙/业余
  │ AI感╱
  └──────────────────────► 偏差剂量
```

- 剂量过低：仍是 AI 感。
- 剂量过高：被感知为"拍坏了"、业余、廉价。
- 最佳剂量随**类型**变化：纪录/伪纪录 > 现实主义正剧 > 商业剧情 > 广告。
- 最佳剂量随**戏剧强度**变化（见"相关性"）：平静戏份低剂量，突发戏份高剂量。

**实验要回答的核心问题之一就是：最佳剂量在哪里。**

## 6. 注入通道：在生产链的哪里植入不完美

| 通道 | 能控制的层 | 方法 | 可靠度 |
|---|---|---|---|
| **分镜首帧**（storyboard 模式） | L3、L4 | 在 image_prompt 里写偏置构图、前景遮挡、受限机位 | ★★★★ 最可控，静帧可预审 |
| **video_prompt.action** | L1、L2、L5 | 用"拍摄者行为与心情"而非"运镜结果"描述镜头 | ★★ 待验证 |
| **camera_motion 枚举** | L1（粗） | 只能选一个枚举；不完美要靠 action 文本补充 | ★ 枚举本身就是"完美化"的来源 |
| **参考视频**（Seedance `@视频1` 运镜参考） | L1、L2 | 上传真实手持素材作为运镜参考 | ★★★ 待验证，潜力最大 |
| **style_description** | L3 | 写全片的拍摄者人格与器材 | ★★ 全局生效 |
| **后期**（ffmpeg） | L1、L2、D4 | 超采样裁切 + 带延迟的重构图轨迹；真实陀螺仪抖动迁移；剪辑点切在动作中 | ★★★★ 完全可控，但只能做 2D |

> 注意：PX Show 的 `camera_motion` 是枚举，这本身就是 D1 的体现——它把运镜离散成"标准动作"。我们的 skill 必须把运镜的"怎么动"挪到 action 文本里去写。

## 7. 待验证假设

| 编号 | 假设 | 若成立的意义 |
|---|---|---|
| H1 | 随机噪声式不完美（"轻微手持晃动"）不提升，甚至降低真实感 | 证明"不完美"本身不是答案，因果才是 |
| H2 | 感知层偏差（延迟、预判失败、发现式构图）显著提升真实感 | 证明"全知视角"是 AI 感主因之一 |
| H3 | 作者层一致偏差提升"有导演感"，且与真实感是两个独立维度 | 证明风格可以被工程化 |
| H4 | 存在倒 U 型剂量曲线，最佳点随类型变化 | 给出可操作的剂量表 |
| H5 | 参考视频通道比文字通道更能传递 L1/L2 偏差 | 决定 skill 的主推方法 |
| H6 | 后期通道可以补偿模型无法生成的偏差 | 决定是否把后期纳入标准流程 |
| H7 | 同等运动幅度下，"有情绪动机"的大运动比"无主"的大运动真人感更高 | 证明真实感的关键是因果，不是幅度（姜文反例） |
| H8 | 同一偏差在不同语境下被感知为不同戏剧功能（紧张/喜剧） | 证明偏差是可编排的叙事工具，不只是质感 |
| H9 | 按导演卡翻译成行为的提示词，比直接写"XX导演风格"更能让观众认出该导演 | 证明 skill 的翻译层有独立价值（产品核心论证） |
| H10 | 直接写导演名只迁移色调和题材，不迁移运镜签名 | 解释为什么名字直写不够——名字本身也会被均值坍缩 |

## 9. 产品形态：导演风格穿透

用户对参数无感知，但认识导演。因此：

```
用户层：选导演（王家卫 / 姜文 / 宁浩 / 侯孝贤 …）
  ↓
翻译层：导演卡 = 五层参数 + 每类场景的偏差配方
  ↓
执行层：PX Show 字段（style_description / image_prompt / camera_motion / action）
```

导演卡是"有因的不完美"的**预设包**：每位导演就是一组稳定的偏差签名。理论（五层模型、参与度、预知对齐、戏剧功能）不暴露给用户，只用来写卡和审卡。

## 8. 风险与边界

- **模型不听话**：模型可能忽略不完美描述，或者把"失焦""晃动"当作伪影生成为崩坏画面。→ 实验中区分"未执行"与"执行但效果差"。
- **与现有 skill 冲突**：`pxshow-director` 的规则（"一个镜头一个主运镜""每帧一个视觉中心""运镜要有理由"）本身就是"标准答案"。新 skill 不推翻它，而是作为其上的**偏差层**：先按 director 定理想执行，再按人格施加 Δ。
- **运镜之外的 AI 感**：光线过干净、表演过完整、无废帧也是来源。本课题先聚焦镜头，框架可迁移到表演（有因的表演失误）、布光（有因的光线缺陷）、剪辑（有因的剪点）。
- **伦理**：越接近真人拍摄感，越需要在发布时标注 AI 生成。
